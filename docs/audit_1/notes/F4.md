# F4 — Layout: sheets of pages, and figures across run TOMLs (a design note)

08_Figures F4. Two questions remain once every figure class can make pages (V80–V87):

1. Several pages on one sheet: the cells of a `plot_points` axis side by side, or a set of figures as
   one panel for a talk or a paper.
2. A figure whose curves come from **another run TOML**: a `compare` across files, not only across
   one file's configurations.

The user decided to build both (2026-10-04): V88, and V89, where sheets are tiled from the drawn
pages (pdflatex, PIL) instead of being redrawn into pads: no Paint or mpl refactor, and each pad
is its page exactly. The note's optional `shared` y title and legend is therefore not offered.

## 1. Sheets: a grid of pages

### What it would be

A new figure class, `sheet`, whose members are **pages**, not objects. It names pages that other
figures already make, and lays them out in a grid. Every pad is drawn exactly as its page is drawn
alone, so a sheet never disagrees with its pages.

```toml
[plot.figures.eta_by_energy]          # one sheet per object: the energies side by side
class   = "sheet"
pages   = "d0[1-4]-x01-y01"           # page globs, matched within each sheet's group
across  = "energies"                  # a page axis (plot_points) spread over the columns
columns = 3                           # default: all of `across` in one row
shared  = ["y", "legend"]             # optional: one y title on the left, one legend for the sheet

[plot.figures.paper_fig3]             # named pages, in this order
class   = "sheet"
pages   = ["18x275/d02-x01-y01", "18x275/eta_algorithms", "18x275/r15"]
columns = 3
```

### Mechanics

- **Runner.** A sheet is planned after the pages it uses. Its TOML lists those pages' TOMLs (the
  ones already written for Paint) and a grid. A page glob matching nothing is an error, as for
  objects.
- **Paint.** A `--sheet SHEET.toml` mode. It opens one canvas sized `columns × page.size`, gives each
  page a TPad, and calls `draw` with that pad as the canvas. That is a refactor: `draw` currently owns
  its `TCanvas`, and would take a pad instead. `shared` keeps the y title on the first column only,
  and draws a single legend: the union of the entries, placed in the last pad or under the grid.
- **mpl.** `plt.subplots(rows, columns)`, each axis drawn by the existing page code given an `ax`. The
  mpl backend already draws into an axis it creates, so this is the same refactor in Python.
- **mkhtml.** No sheets; it says so, as it does for heat maps.
- **Output.** `plots/<backend>/sheets/<name>.<fmt>`, with one section in the index.

### Expected cost

- Paint: about 150 lines (the pad refactor, the sheet mode, the shared legend).
- mpl: about 80 lines.
- Runner: about 60 lines, plus tests.

No change to any page that is drawn alone.

## 2. Figures across run TOMLs

### What it would be

`compare` (V83) takes configurations of the file it is in. Across files, a configuration would be
named as `"<config>:<configuration>"`:

```toml
[plot.figures.inproc_vs_chain]
class          = "compare"
objects        = ["d0*"]
configurations = ["default", "PhotoProduction/InProcZeus:default"]
labels         = ["Pythia → Rivet", "in-process"]
```

### Mechanics

- **Runner.** `compared()` loads the other config (`config.load`) and checks that its configuration
  has the same page and curve axes, so that the pages pair. `cli.others_of` plans it with that
  config's own TOML.
- **Where it lives.** The figure belongs to the file that declares it, so its pages go under this
  run's `compare/<name>/`.
- **When it is drawn.** Only this run's plot stage draws it: the other run's stage does not know
  about it. If the other run has no complete points yet, the figure says it is waiting, as `compare`
  does today. `hep plot` this config draws it later.
- **Identity and quantities.** None of it changes. The other run's points are read as they are, from
  their manifests. Its quantities' labels are its own, and a curve label is its configuration's
  label, then its own curve axes.

### Expected cost

About 40 lines and a test. The member set, the stand-in plans and the page builder are V83's.

## Recommendation

- **Build 2 now.** It is small, it finishes `compare`, and the zeus and InProc configs already want
  it (the same physics through two chains).
- **Build 1 as a second step if sheets are wanted.** It is the only figure work that touches Paint's
  structure, so it should wait for a firm use: a talk or paper figure.

The user decides both.
